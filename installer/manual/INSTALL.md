# BobrovMenu — установка меню Bobrov

Архив `BobrovMenu-manual-install-v<версия>.zip` добавляет вкладку **Bobrov** в AutoCAD 2020
и новее (Windows x64).

| Панель Bobrov | Команды | Плагин, устанавливаемый отдельно |
| --- | --- | --- |
| Палитра XDATA | `XDATAPALETTE` | [acadPaletteSetXDATA](https://github.com/veb86/acadPaletteSetXDATA) |
| Умные выноски | `SL_CREATE`, `SL_CREATE_GROUP`, `SL_UPDATE`, `SL_RULES` | [ACadSmartLeader 0.1.4 или новее](https://github.com/veb86/ACadSmartLeader/releases) |
| База данных | `DB_EDIT` | Плагин управления БД |

Установка не требует прав администратора: все файлы размещаются только в профиле текущего
пользователя (`C:\Users\<имя>\AppData\Roaming`, он же `%APPDATA%`). AutoCAD загружает частичный
файл `BobrovMenu.cuix` со всеми кнопками и значками.

## Состав архива

| Путь в архиве | Назначение | Куда устанавливается |
| --- | --- | --- |
| `AppData\Roaming\Autodesk\ApplicationPlugins\BobrovMenu.bundle\` | пакет автозагрузки AutoCAD | `%APPDATA%\Autodesk\ApplicationPlugins\BobrovMenu.bundle\` |
| `…\BobrovMenu.bundle\PackageContents.xml` | описание пакета и диапазонов AutoCAD Win64 | — |
| `…\BobrovMenu.bundle\Contents\BobrovMenu.cuix` | частичный CUIX с макросами, меню, панелями ленты и значками 16×16 и 32×32 | — |
| `install.cmd` | копирует пакет в профиль пользователя | — |
| `uninstall.cmd` | удаляет пакет из профиля пользователя | — |
| `release-manifest.txt` | версия, commit и SHA-256 файлов архива | — |
| `INSTALL.md` | эта инструкция | — |

## 1. Распаковка

1. Закройте AutoCAD.
2. Windows может пометить скачанные файлы как полученные из интернета. Перед распаковкой
   откройте свойства ZIP-архива и установите флажок **«Разблокировать»** (`install.cmd`
   дополнительно снимает эту отметку).
3. Распакуйте архив в любую временную папку.

## 2. Копирование файлов в профиль пользователя

**Вариант А — автоматически.** Запустите `install.cmd` двойным щелчком (права администратора
не нужны). Скрипт скопирует папку `BobrovMenu.bundle` в `%APPDATA%\Autodesk\ApplicationPlugins`
и заменит предыдущую версию. Другие пакеты в этой папке (в том числе `acadPaletteSetXDATA.bundle`)
не затрагиваются.

**Вариант Б — вручную.**

1. Нажмите `Win+R`, введите `%USERPROFILE%` и нажмите Enter — откроется `C:\Users\<имя>`.
2. Скопируйте туда папку `AppData` из архива и подтвердите слияние папок.

После копирования должны существовать файлы:

```text
%APPDATA%\Autodesk\ApplicationPlugins\BobrovMenu.bundle\PackageContents.xml
%APPDATA%\Autodesk\ApplicationPlugins\BobrovMenu.bundle\Contents\BobrovMenu.cuix
```

## 3. AutoCAD

AutoCAD автоматически загружает пакеты из папки `%APPDATA%\Autodesk\ApplicationPlugins`.

1. Запустите AutoCAD, откройте DWG и выберите вкладку **Bobrov** на ленте.
2. Строка меню в AutoCAD 2021+ по умолчанию скрыта. Чтобы увидеть меню **Bobrov**, включите её
   сами: системная переменная `MENUBAR` = `1` (модуль эту переменную не меняет).
3. Нажмите **Палитра XDATA** для открытия или скрытия палитры «Свойства XDATA».
   На панели **Умные выноски** выберите нужное действие. На панели **База данных** нажмите
   **Редактор БД**, чтобы открыть плагин управления БД.

Кнопки используют глобальные имена команд с префиксом `_` для русской и английской версий AutoCAD.
При активной команде макрос сначала отменяет её. Если AutoCAD сообщает о неизвестной команде,
проверьте установку соответствующего плагина.

### Если меню или вкладка не появились

1. Выполните команду `CUILOAD` (или `MENULOAD`): в списке загруженных групп должна быть группа
   `BOBROVMENU`. Если её нет, проверьте пути из шага 2 и наличие `PackageContents.xml`.
2. Вкладка добавляется в рабочие пространства автоматически (`DefaultDisplay="AddToWorkspace"`).
   Если в своём рабочем пространстве вы её скрыли, включите её снова: правый щелчок на ленте →
   «Показать вкладки» → **Bobrov**, или в редакторе `CUI` перетащите вкладку **Bobrov** из
   группы `BOBROVMENU` в рабочее пространство.
3. Если в рабочем пространстве меню **Bobrov** не отображается в строке меню, добавьте его так
   же через редактор `CUI` (рабочее пространство → «Меню»). Модуль сам рабочие пространства не
   меняет.

## 4. Обновление

1. Закройте AutoCAD.
2. Распакуйте новую версию архива и запустите `install.cmd`. Скрипт заменит `BobrovMenu.bundle`
   и удалит файлы старого меню. При обновлении вручную сначала удалите прежнюю папку
   `BobrovMenu.bundle`, затем скопируйте пакет из нового архива.
3. Если после обновления с ACadSmartLeader 0.1.3 в профиле осталась группа `ACADSMARTLEADER`,
   снимите её через `CUIUNLOAD` и обновите сам плагин выносок до 0.1.4 или новее.

## 5. Удаление

1. Закройте AutoCAD.
2. Запустите `uninstall.cmd` или удалите вручную папку:

   ```text
   %APPDATA%\Autodesk\ApplicationPlugins\BobrovMenu.bundle
   ```

Установленные отдельно плагины продолжают предоставлять команды из командной строки.
