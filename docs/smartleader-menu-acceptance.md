# Приёмка кнопок выносок и БД на вкладке Bobrov

[Уточнение владельца в задаче #5](https://github.com/veb86/ACadMenu/issues/5#issuecomment-7101581925)

CI проверяет единственную вкладку Bobrov, привязки кнопок к глобальным макросам,
размещение кнопок по панелям, уникальные значки 16×16 и 32×32 внутри CUIX и состав
установочного архива. Тест установки на Windows заменяет старый пакет с тремя
DLL меню и проверяет сохранность соседних пакетов.

Чтение вкладки, трёх панелей, кнопок, макросов и имён значков проверено через
`AcCui.dll` AutoCAD 2020–2024. Для повторения нужны .NET 10 и `AdWindows.dll` рядом с
`AcCui.dll`.

```bash
dotnet run experiments/Inspect-BobrovRibbonReader.cs -- /path/to/AcCui.dll installer/BobrovMenu.bundle/Contents/BobrovMenu.cuix
```

## Проверка в AutoCAD

1. Возьмите архив из артефакта CI `BobrovMenu-release`. Установите совместимые
   версии ACadSmartLeader 0.1.4+, acadPaletteSetXDATA и плагина управления БД.
   Запишите версию и commit меню из `release-manifest.txt` и версию AutoCAD из `ABOUT`.
2. Запустите `install.cmd` и откройте DWG. Через `CUILOAD` проверьте группу
   `BOBROVMENU`. На ленте откройте вкладку **Bobrov** и проверьте панели
   **Палитра XDATA**, **Умные выноски** и **База данных**.
3. Проверьте значок и действие каждой кнопки.

   | Панель и кнопка | Что должно произойти |
   | --- | --- |
   | Палитра XDATA → Палитра XDATA | Палитра «Свойства XDATA» открывается и скрывается. |
   | Умные выноски → Создать | `SL_CREATE` запрашивает точку для новой выноски. |
   | Умные выноски → Создать групповую | `SL_CREATE_GROUP` запускает создание групповой выноски. |
   | Умные выноски → Обновить | `SL_UPDATE` запускает обновление выносок. |
   | Умные выноски → Правила | `SL_RULES` открывает редактор правил. |
   | База данных → Редактор БД | `DB_EDIT` открывает плагин управления БД. |

4. Повторите после обновления с BobrovMenu 0.1.x и после смены рабочего пространства.
   Убедитесь, что есть одна вкладка **Bobrov** с тремя панелями. Для профиля с
   ACadSmartLeader 0.1.3 примените шаг обновления для старой группы.
   [Инструкция по установке](../installer/manual/INSTALL.md#4-обновление)
5. Сохраните снимок вкладки и историю команд с версией AutoCAD и SHA архива.

Для этой проверки требуется установленный AutoCAD с плагинами команд. CI выполняет
проверки CUIX и архива.
